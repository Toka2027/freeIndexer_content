## Short Verdict

Give the practical recommendation early and name the ICP the verdict is for.

## Comparison Table

Compare by user type, cost model, workflow fit, technical complexity, and limitations.

## When To Choose Each Option

Route readers by ICP and use case.

## Decision Tree

Show how the reader should choose based on volume, technical ability, reporting
needs, and repeatability.

## Workflow Example

Use a realistic scenario, not a feature checklist.

## Where FreeIndexer Fits

Explain the FreeIndexer path without overstating claims.

## FAQ

Answer commercial questions. Use `###` for each question.

## Next Step

Use the reader-facing next step from frontmatter.
