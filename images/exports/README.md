# Image Exports

Generated FreeIndexer hero images live here.

Expected files:

- canonical hero: `images/exports/{slug}-hero.png`
- subject image: `images/exports/subjects/{slug}-subject.png`
- per-template QA hero: `images/exports/heroes/{slug}-tNN-hero.png`
- validated overlay: `images/exports/validated/{slug}-tNN-validated.png`

Do not commit large generated exports unless the team decides hero images should be versioned in this repo.
